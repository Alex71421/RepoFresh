# RepoFresh
## Краткое описание:
**RepoFresh** — это кроссплатформенное консольное приложение, написанное на Python для автоматического отслеживания состояния локальных Git-репозиториев.
## Возможности:
1) **Управление списком репозиториев:** добавление, удаление и просмотр отслеживаемых Git-репозиториев
2) **Автоматическая проверка:** фоновый мониторинг состояния репозиториев с заданным интервалом
3) **Массовое обновление:** одновременное обновление всех отстающих репозиториев (git pull)
4) **Статус актуальности:** определение отстающих коммитов и неотправленных изменений
5) **Автоматический запуск:** восстановление состояния при перезапуске приложения

## Требования
- Python 3.7+ 
- Git (установленный и доступный в PATH)
- Доступ к интернету (для проверки удаленных репозиториев)

## Установка и запуск
1. **Клонирование репозитория**
````
git clone https://github.com/Alex71421/RepoFresh.git
cd RepoFresh
````
2. **Запуск приложения**
````
python repofresh.py
````
## Руководство по использованию
### 1. Добавление репозитория
Выберите пункт меню "2. Добавить репозиторий"
- Введите путь к локальному Git-репозиторию (например: C:\Projects\myapp или ~/projects/myapp)
- Примите или измените предложенное название

### 2. Просмотр статуса репозиториев
Выберите пункт меню "1. Показать список репозиториев"

Для каждого репозитория отображается:
- ✅ Актуален — локальная и удаленная версии синхронизированы
- ❌ Отстает на N коммитов — есть новые коммиты в удаленном репозитории
- ⚠️ Неотправленных: N — есть локальные коммиты, не отправленные на удаленный репозиторий

### 3. Автоматическая проверка
Выберите пункт меню "6. Запустить автоматическую проверку"
- Укажите интервал проверки в минутах (по умолчанию: 30)
- Приложение будет автоматически проверять все репозитории в фоновом режиме
- Для остановки выберите пункт "7. Остановить автоматическую проверку"

### 4. Массовое обновление
Выберите пункт меню "5. Обновить все репозитории"
- Приложение автоматически обновит только те репозитории, которые отстают от удаленной версии
- Уже актуальные репозитории будут пропущены

## Детальное описание модулей
### repofresh.py — Основное приложение
**Назначение:** Главный модуль, управляющий всем жизненным циклом приложения.

**Основные функции:**
1. **main()**
    - Загрузка конфигурации при запуске
    - Автоматическое восстановление фоновой проверки
    - Обработка выбора пользователя

## Модуль работы с конфигурацией
**Назначение:** Управление файлом конфигурации в формате JSON.

**Основные функции:**
1. **load_config()**
    - Загрузка конфигурации из JSON-файла
    - Автоматическое создание начальной конфигурации при первом запуске

2. **save_config(config)**
    - Сохранение конфигурации с форматированием

**Структура конфигурационного файла:**
````
json
{
  "repositories": [
    {
      "name": "my-project",
      "path": "/full/path/to/repository"
    }
  ],
  "version": "1.0",
  "config_path": "/path/to/repofresh_config.json",
  "auto_check": {
    "enabled": true,
    "interval_minutes": 30,
    "started_at": "2024-01-15 10:30:00"
  }
}
````
## Модуль валидации репозиториев
**Назначение:** Проверка корректности путей и уникальности репозиториев.

**Основные функции:**
1. **is_valid_git_repository(path)**
    - Проверка существования пути
    - Подтверждение, что путь ведет к директории
    - Проверка наличия папки .git

2. **get_repo_name_suggestion(path)**
    - Генерация предложения имени на основе имени папки
    - Автоматическое извлечение базового имени из пути

3. **is_unique_repo_name(config, name)**
    - предотвращение дублирования имен

4. **is_unique_repo_path(config, name)**
    - предотвращение добавления одного репозитория дважды

## Модуль управления репозиториями
**Назначение:** Взаимодействие с пользователем для управления списком репозиториев.

**Основные функции:**
1. **add_repository(config)**
    - Интерактивный диалог добавления нового репозитория
    - Автопредложение названия
    - Проверка всех условий перед добавлением

2. **remove_repository(config)**
    - Отображение текущего списка репозиториев
    - Удаление по имени
    - Подтверждение успешного удаления

3. **clear_all_repositories(config)**
    - Безопасная очистка всего списка
    - Требование подтверждения для предотвращения случайного удаления

## Модуль Git-операций
**Назначение:** Выполнение Git-команд и анализ состояния репозиториев.

**Основные функции:**
1. **run_git_command(repo_path, command)**
    - Безопасное выполнение Git-команд через subprocess
    - Возврат текстового вывода команд

2. **check_repository_status(repo_path)**
    - Определение текущей ветки
    - Выполнение git fetch для обновления информации
    - Сравнение локальных и удаленных коммитов 
    - Формирование понятного статуса с эмодзи

3. **update_repository(repo_path)**
    - Выполнение git pull для обновления репозитория

4. **update_all_repositories(config)**
    - Массовое обновление всех репозиториев
    - Обновление только отстающих репозиториев
    - Отчет о результатах обновления

## Модуль отображения информации
**Назначение:** Представление данных пользователю в удобном формате.

**Основные функции:**
1. **show_menu(config)**
    - Отображение всех доступных функций
2. **list_repositories(config)**
    - Форматированный вывод всех репозиториев
    - Отображение текущего статуса для каждого репозитория
3. **show_auto_check_status(config)**
    - Отчет о состоянии автоматической проверки
    - Отображение интервала и времени запуска
    - Индикация количества отслеживаемых репозиториев

## Модуль автоматической проверки
**Назначение:** Фоновый мониторинг состояния репозиториев.

**Основные функции:**
1. **start_auto_check(config, interval)**
    - Запуск фонового потока проверки
    - Настройка пользовательского интервала
    - Автоматическое сохранение состояния в конфигурации

2. **stop_auto_check(config)**
    - Безопасная остановка фоновой проверки
    - Сохранение времени остановки

3. **auto_check_loop() (внутренняя функция)**
    - Циклическая проверка всех репозиториев
    - Логирование с временными метками
